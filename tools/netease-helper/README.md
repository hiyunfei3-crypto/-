# 网易云音乐本机播放助手

在主播的 Windows 电脑上打开并登录网易云音乐，然后在普通 Windows 终端（与客户端同一桌面会话）中于本目录运行：

```powershell
node server.mjs
```

保持终端窗口打开，将输出的配对码填入主播控制台，点击“连接助手”，看到“本机助手已连接”即完成配对。助手只监听 `127.0.0.1:43871`，仅接受配置的网站来源。若发布到新的域名，可先设置 `SONGLIST_SITE_ORIGIN` 为该网站的完整 origin（例如 `https://example.com`）。不要把配对码发送给观众。

不经过云端队列，先单独测试这台电脑的播放链路：在项目根目录另开一个终端，运行 `node tools/netease-helper/test-play.mjs <配对码> "河流 demo"`。看到“客户端已切换到”并听到音乐，就说明本机搜索和播放链路正常。同名多版本会选择网易云搜索结果中第一个歌名完全匹配的版本。

主播接受点放请求后点击“播放”：后台先把歌名交给助手，助手从网易云歌曲搜索接口选取第一个歌名完全匹配的结果，再向本机客户端发送播放指令；客户端窗口切换到指定歌名后，后台才将云端请求标为“进行中”，并提示选中版本的歌手。搜索不到、客户端未打开或无法确认切歌时，后台保留原状态并显示错误。点唱不会调用助手。

主播可以在配对成功后开启“自动续播点放”。后台保持打开时，会按提交时间依次播放点放请求；第一首完成后自动标为已完成，再开始下一首。遇到点唱请求时等待主播手动处理。由于当前网易云客户端没有提供可用的播放结束事件，助手按搜索接口提供的曲长估算结束时间；暂停、拖动进度或广告可能造成提前或延后切歌，此时应关闭自动续播并手动处理。浏览器后台标签页可能限制定时器，直播时建议保持主播后台可见。关闭后台或助手后不会自动续播。

当前电脑的网易云版本只暴露空的 CEF 容器，无法可靠使用 Windows UI Automation。助手现在使用网易云的网页搜索接口和客户端已注册的 `orpheus://` 播放协议，并直接调用本机 `cloudmusic.exe`。实机测试已确认客户端会切换到指定歌曲；窗口标题不能证明声音已经输出、会员歌曲可播，也不能保证客户端未来版本继续支持此协议。这两个接口并非经官方文档确认的稳定开放 API，直播前请用实际曲目试听。按主播当前要求，同名歌会自动选搜索排序中的第一个完全同名版本；助手不下载或绕过付费歌曲。

部署远程队列时，将 `integrations/unicloud/database/songlist_requests.schema.json` 上传至服务空间，并上传更新后的 `songlist-api` 云函数；网页需一起发布以更新同源的 uniCloud bridge。数据库的客户端权限关闭，由云函数读写。
